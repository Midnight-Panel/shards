# Voice & Media Shard Collection

Voice servers and audio streaming nodes for **Midnight Panel**.

## Available Shards

| Service | Runtime | Default Port | Status | Description |
|---|---|---|---|---|
| **[TeamSpeak 3](teamspeak3.json)** | C++ Native | 9987 (UDP) | Verified | Low-latency voice communication server |
| **[Lavalink](lavalink.json)** | Java 21 / 17 | 2333 (HTTP/WS) | Verified | Standalone audio sending node for Discord bots |

## Features
- Dynamic audio port mapping.
- Automatic latest release retrieval.
- Ready-to-go `application.yml` and license accept flags.
